## OceanFleet App 

### Description:

* A Java-based console application designed to manage vessel information and performance records using Object-Oriented Programming (OOPS) concepts.

* Demonstrates Java Collections, searching, filtering, and clean code practices through progressive, use-case-driven implementation.

### Use Cases:

#### Use Case 1: Create Vessel Model

Defines a Vessel class with attributes, constructors, and getter/setter methods to represent vessel information and performance details.

#### Use Case 2: Store Vessel Records Using List

Stores multiple vessel objects in a dynamic List collection using the VesselUtil class, maintaining insertion order and enabling efficient sequential traversal.
